# 📷 GoPick

**CLI-утилита, которая скачивает изображения с любого сайта: читает HTML, витрины GameStores разбирает через их JSON-API, а если картинок нет — рендерит страницу в headless-браузере; найденные картинки раскладываются по папкам форматов**

## Особенности

* Три способа сбора, переключаются сами: сначала читается обычный HTML, для витрин GameStores запрашивается их JSON-API, а если картинок всё равно нет — страница открывается в headless-браузере и собирается уже после выполнения JavaScript.
* **Витрины GameStores без браузера**: магазины на `gamestores.app` (и на своих доменах, собранных на этом движке) помечают себя ссылками на `cdn.gamestores.app`. GoPick распознаёт их и берёт данные из `/api/v1/info` и `/api/v1/products.list` — все товары и их картинки скачиваются сразу, без выбора сервера и без запуска Chrome.
* Клик по кнопке перед сбором: `-click-text "text"` нажимает самую вложенную кнопку с таким текстом, `-click "<css>"` — элемент по селектору. Нужно там, где товары и картинки появляются только после выбора сервера или открытия каталога, а движок сайта — не GameStores.
* Прокрутка страницы до низа, чтобы догрузились ленивые картинки.
* Профиль браузера: cookies и авторизация сохраняются между запусками.
* Параллельная загрузка в несколько воркеров. Ошибка одного файла не роняет остальные: 404/403 просто попадают в итоговый счёт.
* Сортировка по форматам: каждый файл ложится в свою папку — `png/`, `svg/`, `jpg/`, `webp/`, `gif/`, а если расширение определить нельзя — в `unknown/`.
* Имя корневой папки — домен сайта без схемы: `https://example.com/page` → `example.com`.
* Лог `log.txt` рядом с exe ведётся всегда: адрес, режим, заголовок, найденные картинки, **все кнопки и ссылки страницы**, текст страницы на случай, если нужных картинок среди найденных нет.
* Интерактивное меню из трёх пунктов, если запустить без аргументов. Всё остальное утилита делает сама.

## Ограничения

* Режим рендера использует уже установленный браузер (Chrome, Chromium, Edge или Brave). Без него по-прежнему работают разбор HTML и API-режим витрин GameStores.
* Сайты с капчей, Cloudflare или обязательной авторизацией берутся только через `-profile` с уже пройденным входом.
* Клик по кнопке выполняется один раз. Если каталог открывается кнопкой «Показать ещё», которую надо нажимать многократно, такие страницы не обходятся.
* Если содержимое приходит по WebSocket и DOM вообще не меняется, не поможет ни рендер, ни клики.
* Скачиваются только изображения — видео, документы и архивы не трогаются.

## Установка

### Требования

* Go 1.25+
* Windows 10+
* Браузер Chrome, Chromium, Edge или Brave

### Сборка

```
go build -o GoPick.exe ./cmd/gopick
```

### Использование

1. Запустите `GoPick.exe` без аргументов. Откроется меню — нажать Enter и ввести адрес сайта.
2. Если картинки появляются только после действия на странице (движок не GameStores), выберите пункт `1` и введите текст кнопки, например `Выбрать`. Подсмотреть доступные кнопки можно в `log.txt`.
3. Утилита скачает картинки в папку с именем домена и разложит их по форматам. Дальше можно сразу вводить следующий адрес — окно закроется только по пустой строке.

То же самое одной командой:

```
GoPick.exe https://example.com
GoPick.exe https://yrsproject.gamestores.app
GoPick.exe -render -click-text "Выбрать" https://example-shop.com
```

Результат выглядит так:

```
example.com/
├── gif/
├── jpg/
├── png/
├── svg/
├── unknown/
└── webp/
```

Флаги:

* `-w <число>` — сколько файлов качать одновременно (по умолчанию 8)
* `-render` — сразу рендерить страницу в браузере, минуя разбор HTML
* `-no-render` — не переходить в режим рендера, если в HTML картинок нет
* `-click-text "<текст>"` — кликнуть по кнопке с этим текстом
* `-click "<css>"` — кликнуть по элементу, найденному CSS-селектором (несколько — через запятую)
* `-wait <длительность>` — пауза после загрузки страницы в режиме рендера (по умолчанию 3s)
* `-scroll` / `-no-scroll` — прокручивать ли страницу для ленивых картинок (по умолчанию включено)
* `-profile <каталог>` — каталог профиля браузера для cookies и авторизации
* `-browser <путь>` — путь к Chrome/Chromium/Edge (по умолчанию ищется автоматически)
* `-list` — только показать найденные ссылки, ничего не скачивая

## Гайд: магазин на gamestores.app и кнопка «Выбрать»

Большинство RUST/донат-магазинов крутится на движке **GameStores** — например `https://yrsproject.gamestores.app` или `https://rustcasta.ru`. Это React/Vite-одностраничник: самих товаров в HTML нет, всё рисуется скриптами.

**Что видно в браузере.** Открыв такой магазин, вы попадаете на выбор сервера: карточки серверов с кнопкой **«Выбрать»**. Пока сервер не выбран, товары не показываются — они подгружаются под конкретный сервер.

**Что делает GoPick.** Ему кликать не нужно: он замечает ссылки на `cdn.gamestores.app`, понимает, что это витрина GameStores, и забирает данные напрямую из её JSON-API.

1. Запустите обычную команду:
   ```
   GoPick.exe https://yrsproject.gamestores.app
   ```
2. В выводе будет:
   ```
   OK  режим: API (GameStores)
   OK  изображений: 103
   ```
   За кулисами GoPick делает два запроса:
   * `GET /api/v1/info` — название магазина, лого и фон, список серверов;
   * `GET /api/v1/products.list` — все категории и товары вместе с их картинками (поле `img`, а также `<img>` из описаний).
3. Все товары скачиваются сразу — **без выбора сервера и без запуска Chrome**, в папку с именем домена.

### Когда всё-таки надо кликнуть «Выбрать»

Если магазин не на GameStores (или вы явно форсируете рендер флагом `-render`), товары могут появляться только после нажатия кнопки. Тогда GoPick открывает браузер и жмёт по тексту:

```
GoPick.exe -render -click-text "Выбрать" https://example-shop.com
```

Точный текст кнопки всегда есть в `log.txt`, в разделе «Кнопки и ссылки, по которым можно кликнуть». Если надпись другая, подставьте её:

```
GoPick.exe -render -click-text "Выбрать сервер" https://example-shop.com
```

Тот же клик годится и для витрины GameStores, если её API по какой-то причине недоступен — тогда сервер выбирается вручную:

```
GoPick.exe -render -click-text "Выбрать" https://yrsproject.gamestores.app
```

А `-click "<css>"` попадает в элемент точно, по CSS-селектору, если текста кнопки недостаточно.

## Вопрос - ответ

<details>
  <summary><b>Почему скачались не все картинки, а товаров вообще нет?</b></summary>
  <br>
  Скорее всего сайт показывает товары только после выбора сервера или открытия каталога. Если это магазин на <b>gamestores.app</b> — кликать не нужно: GoPick распознаёт витрину и берёт товары из её API (см. раздел «Гайд» выше). Если движок другой, откройте <code>log.txt</code>, найдите раздел «Кнопки и ссылки, по которым можно кликнуть» и запустите с этим текстом: <code>GoPick.exe -render -click-text "Выбрать" https://example-shop.com</code>.
</details>
<details>
  <summary><b>Почему в браузере я вижу товары сразу, а утилита их не находит?</b></summary>
  <br>
  Потому что браузер помнит ваш выбор сервера в cookie, а GoPick стартует с чистым профилем. Либо укажите кнопку через <code>-click-text</code>, либо запустите один раз с <code>-profile %USERPROFILE%\GoPickProfile</code>, чтобы состояние сохранялось между запусками.
</details>
<details>
  <summary><b>Зачем нужен log.txt?</b></summary>
  <br>
  Он показывает, что именно увидела утилита: режим, заголовок, высоту страницы, список найденных картинок, все кнопки и ссылки, начало текста страницы. По нему видно, почему картинок мало и что нажать. Файл дописывается блоками, поэтому история запусков сохраняется.
</details>
<details>
  <summary><b>Почему папка называется доменом, а не example_com_images?</b></summary>
  <br>
  Так короче и понятнее: папка результата совпадает с адресом сайта без схемы. Порт заменяется подчёркиванием, потому что двоеточие недопустимо в имени файла Windows: <code>127.0.0.1:8080</code> → <code>127.0.0.1_8080</code>.
</details>
<details>
  <summary><b>Почему имена файлов вида i.postimg.cc_image-2.png?</b></summary>
  <br>
  У разных картинок с чужого CDN часто одинаковое имя <code>image.png</code>. Чтобы файлы не затирали друг друга, к имени добавляется хост источника, а если и он совпадает — короткий хеш адреса.
</details>
<details>
  <summary><b>Можно ли пользоваться без браузера?</b></summary>
  <br>
  Да. Для сайтов, где картинки есть в HTML, браузер не нужен вовсе, а витрины GameStores и так разбираются через JSON-API — <code>-no-render</code> запретит переход в режим рендера. Разбор HTML и API-режим автономны и не требуют ничего, кроме самого exe.
</details>
<details>
  <summary><b>Как пересобрать иконку приложения?</b></summary>
  <br>
  Иконка рисуется кодом: <code>go run ./tools/genicon assets</code>, затем ресурс <code>go run github.com/akavel/rsrc@latest -ico assets/icon.ico -arch amd64 -o cmd/gopick/rsrc_windows_amd64.syso</code> и обычная сборка.
</details>
